【使い方（最初に必ず実施）】

1) このプロンプトの先頭に、ProjectX_MANIFEST.txt に記載されている
   [KNOWLEDGES] ブロックを丸ごと貼り付けてください。
   - [KNOWLEDGES] には、現時点で有効な merged.md および
     差分となる summary ファイルが含まれている想定です
2) URL の貼り付けにより、各ファイルが
   「参照（添付相当）」として認識されている前提で、以下を実行してください。

---

あなたは、上部（または直前）に貼り付けられた [KNOWLEDGES] に含まれるファイルを参照し、
同一プロジェクトの知識を統合して、最新の正本（merged.md）を作成または更新してください。

新しい議論や追加検討は不要です。
参照できた情報のみを使用してください。

【重要な前提】
- 新しい内容は一切追加しないでください
- 推測・補完・一般化は行わないでください
- 表現の言い換えや内容の意味が変わる再構成は行わず、元の文書・成果物の言い回しを尊重してください
- summary / merged に含まれる成果物（文章・計画・設計・プログラムコード等）は、内容を改変せず、原文のまま扱ってください
- merged.md が参照できた場合:
  - 現時点の正本としてとして最優先で扱ってください
  - summary（連番が大きいほど新しい知識）は、merged.md を前提として追加された差分として扱ってください
- merged.md が参照できなかった場合:
  - summary（連番が大きいほど新しい知識）を、新しい知識ほど優先して扱ってください
- Copilot 自身の判断で情報を削除・圧縮しすぎないでください
- 参照できないファイルがある場合は、推測せず「参照不可」と明記してください
- 内容の正確性を最優先してください

【出力に関する方針】
- 出力は Markdown として扱ってください
- 出力は必ず 2 部構成としてください
  1) 監査ログ（コードブロック外）
  2) merged.md 本文（外側 Markdown コードブロック内）
- merged.md 本文は、1 つの外側 Markdown コードブロックで囲んでください
- 成果物の中に Markdown やプログラムコードが含まれる場合は、それぞれ適切なコードブロックとして入れ子で表現してください
- 外側のコードブロックは、内部で使用されるコードブロックと衝突しない長さのバッククオートを使用してください
- バッククオートの個数は、内容に応じて Copilot 自身が安全に選択してください

【外側コードブロックの終了ルール（重要）】
- 外側 Markdown コードブロックは、内容がすべて完結した時点で **1 回だけ** 閉じてください
- 外側コードブロックを閉じた後には、**いかなる文字・記号・空行も出力しないでください**
- 「（以上）」などの終了を示す文言は、**外側コードブロックの内側の最終行としてのみ** 記載してください
- 構文補完・安全確認・装飾目的で、外側コードブロック閉鎖後に追加のバッククオートを出力してはいけません

【成果物の扱いに関する方針（重要）】
- merge における「成果物スナップショット」には、**実際に作成された一次成果物のみ** を含めてください
- 以下のような内容は、成果物として採用しないでください
  - 知識バックアップ全文
  - merge / backup / rescue の出力そのもの
  - 「知識バックアップ」「知識マージ」などの構造化された知識保存ドキュメント
- 上記に該当する内容は、成果物ではなく「参照元」として扱い、成果物スナップショットには含めないでください

## 6. 成果物スナップショット（要約・編集禁止）
- このセクションには、会話や検討の過程で **実際に作成・編集された一次成果物のみ** を記載してください
- 一次成果物とは、以下のようなものを指します
  - プログラムコード
  - 設計書・仕様書・計画書
  - 利用可能な文章原稿
- 以下の内容は、成果物として記載しないでください
  - 知識バックアップ全文
  - 知識マージ（merged.md）や rescue / backup の出力そのもの
  - それらをそのまま転記した構造化ドキュメント
- 成果物が複数ある場合は、区別が分かる見出しを付けてください
- 実質的に同一な成果物が複数ある場合は、最新のものを正として統合してください
- 内容に差分がある場合は、差分が分かる形で併記してください
- 明確な一次成果物が存在しない場合は、「なし」と記載してください
- 成果物の見出しには、番号（6-1, 6.1 など）を使用せず、必ず「成果物 1」「成果物 2」の形式で記載してください
