この会話は、会話上限に到達している、または間もなく到達します。

新しい議論や追加検討は不要です。
この会話に含まれる情報のみを使用して、以下の形式で「知識バックアップ」を作成してください。

【重要な前提（必須）】
- 新しい内容は一切追加しないでください
- 推測・補完・一般化は行わないでください
- 表現の言い換えや内容の意味が変わる再構成は行わず、会話中の言い回しを尊重してください
- 会話中で作成・編集された成果物（文章・計画・設計・プログラムコード等）は、内容を改変せず、原文のまま保存してください
- Copilot 自身の判断で情報を削除・統合・圧縮しないでください
- 会話中に明示されていない情報は「不明」「記載なし」と明記してください
- 内容の正確性を最優先してください

【許可される整理】
- 会話中に明示された情報を、指定された見出しの下に再配置すること
- 明示された判断・結論・制約を抽出すること
- 成果物を原文のまま保存すること

【禁止される補完】
- 会話中に明示されていない事実を追加すること
- 一般知識で不足部分を埋めること
- 成果物本文を言い換えること
- Copilot の推測を確定事項として扱うこと

【出力に関する方針】
- 出力は Markdown として扱ってください
- 全体を 1 つの外側 Markdown コードブロックで囲んでください
- 成果物の中に Markdown やプログラムコードが含まれる場合は、それぞれ適切なコードブロックとして入れ子で表現してください
- 外側のコードブロックは、内部で使用されるコードブロックと衝突しない長さのバッククオートを使用してください
- バッククオートの個数は、内容に応じて Copilot 自身が安全に選択してください

【外側コードブロックの終了ルール（重要）】
- 外側 Markdown コードブロックは、内容がすべて完結した時点で **1 回だけ** 閉じてください
- 外側コードブロックを閉じた後には、**いかなる文字・記号・空行も出力しないでください**
- 「（以上）」などの終了を示す文言は、**外側コードブロックの内側の最終行としてのみ** 記載してください
- 構文補完・安全確認・装飾目的で、外側コードブロック閉鎖後に追加のバッククオートを出力してはいけません

【出力フォーマット】

以下は、出力内容の構造を示すためのガイドです。
見出し名・順序・構成は維持してください。
各セクションの記載量・記載回数・入れ子の深さは、内容に応じて柔軟に判断してください。

# 知識バックアップ（会話上限到達）

## 0. バックアップ対象の位置づけ
- このバックアップが何を保存するためのものかを記述してください

## 1. 会話の目的
- 会話全体の目的を文章で記述してください

## 2. 前提条件・制約
- 会話中で明示された前提条件や制約を記述してください

## 3. 得られた判断・結論
- 会話を通じて得られた判断や結論を記述してください

## 4. 未解決の論点・保留事項
- 未解決の論点があれば記述してください
- 存在しない場合は「なし」と明記してください

## 5. 参照された資料一覧
- 会話中で参照された資料を、分かる範囲で記述してください

（例）
- 資料名：
  - 種別：
  - 保存場所：
  - 参照URL：
  - 会話内での役割：

## 6. 成果物スナップショット（要約・編集禁止）
- このセクションには、**会話中で実際に作成・編集された一次成果物のみ** を記載してください
- 一次成果物とは、文章原稿・設計書・計画書・プログラムコード等、再利用可能な成果物を指します
- 知識バックアップ本文、知識マージ（merged.md）、rescue / backup の出力そのものなど、**二次的に生成されたドキュメントは成果物として記載しないでください**
- 会話中で作成・編集された成果物を、原文のまま、完全な形で記載してください
- 成果物が複数ある場合は、区別が分かるように見出し等を用いて整理してください
- 明確な成果物が存在しない場合は「なし」と記載してください
- 成果物の見出しには、番号（6-1, 6.1 など）を使用せず、必ず「成果物 1」「成果物 2」の形式で記載してください

（例）
### 成果物 1（例）
（ここに原文をそのまま記載）
